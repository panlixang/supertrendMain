判读：
  · 若 C − B ≤ 0 → 「按 ER 分档切出场」没有价值，弱档多开的单只是噪声（甚至更差）
  · 若 C − B > 0 且 C > 参照1 → 分档出场是真收益，值得在生产里打开 quick_enabled
  · 若 B ≫ 参照1 而 C ≈ B → 价值来自「多开低 ER 的单」而非差异化出场，说明
    闸门阈值本身设错了（把 er_min 调低即可，不需要两套规则）
